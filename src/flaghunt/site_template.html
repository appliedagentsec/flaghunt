Flaghunt

A sandboxed harness for benchmarking AI agents on capture-the-flag challenges. Bring any agent, run it against the challenges, and replay every step it took.

How a run works

The agent thinks on your machine and acts inside a sealed box

Flaghunt splits every run across three places. The model only ever sees text. Commands only ever run in a throwaway container with no network. Your API key never leaves the harness.

Sandbox container

The hands

  • --network none
  • --cap-drop ALL, unprivileged user
  • 1 CPU, 1 GB RAM, 256 processes
  • Challenge files in /work, no keys
  1. Load the challengeA folder with a description, files and the flag's hash.
  2. Start a fresh sandboxCopy the files in. Nothing carries over between runs.
  3. Let the agent workIt reads the brief, runs commands, reads output and decides what to try next.
  4. Score and recordA correct flag ends the run. Every step is saved for the leaderboard and replay.

Methodology

How the numbers are produced

Every result on this page comes straight from a transcript file in the repository. Nothing is edited by hand. The only changes are that API keys are scrubbed and correct flags are masked.

Setup

Limitations

  • Small sample. Few challenges and few attempts per agent. Treat the scores as a demo, not a ranking.
  • Self-written challenges. Difficulty labels are the author's estimate and have not been calibrated against human solvers.
  • Training-data exposure. Public challenges can end up in future models' training data, which would inflate their scores.
  • Different budgets. When agents ran with different limits, the setup table lists each one.

      Try it
      
Run it yourself, with any model

      
Everything runs on your own machine. Use a free local model, or your own API key.

    

    

      

        
Quick start

        
# one-time setup
uv sync
uv run flaghunt sandbox build

# free: a local model through Ollama
uv run flaghunt run --agent agents/local-qwen.yaml --all

# compare every agent you've run
uv run flaghunt results

        
      

      

        
Bring your own agent

        
Either a YAML file that picks a provider and model, or a Python class. Every action goes through task, so all agents get the same sandbox, budget and transcript.

        
from flaghunt.agents import Agent, Task

class MyAgent(Agent):
    name = "my-agent"

    def solve(self, task: Task) -> None:
        out = task.shell("file *")   # runs in the sandbox
        if task.submit("flaghunt{guess}"):
            return

        
      

    

  


  

    

      

        Scope and safety
        
Built for defensive research

        
Agents only act inside a disposable container with no network access, no Linux capabilities and strict resource limits. The harness has no way to point an agent at a real system, and challenges are self-contained files. Found a way out of the sandbox? Please report it privately, as described in the security policy.

      

      

        About
        
Applied Agent Security Lab

        
An independent research group studying how well AI agents perform on security tasks and how to run them safely. Flaghunt is its first project. Contributions, new challenges and agent submissions are welcome on GitHub.
